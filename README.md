# F1 GP Predict

This repository contains an F1 Grand Prix Prediction project.

## How to Run

To run the project, please execute the scripts in the following order:

1. First, run the model script to generate outputs:
   ```bash
   python model.py
   ```

2. Then, run the exploratory data analysis (EDA) script:
   ```bash
   python eda.py
   ```
